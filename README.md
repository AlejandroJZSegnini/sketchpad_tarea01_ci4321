## Requisitos

- Node.js 20 o superior
- npm
- Un navegador que soporte webgl2

## Run

1. Instalar las dependencias. Necesita conexion a internet para esto.

   ```
   npm install
   ```

2. Iniciar el servidor de desarrollador.

   ```
   npm run dev
   ```

3. Abrir `http://localhost:5173` en su buscador.

## Uso

- Presionar "cambiar figura" para pasar a la siguiente figura (triangulo a cuadrado a hexágono a círculo y de vuelta).
- Presionar "cambiar color" para pasar al siguiente color (rojo a verde a azul y de vuelta).
